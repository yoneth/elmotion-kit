## Cara Pakai

1. Buka browser ke `https://men.qzz.io/elmotionkit/wp-admin`
2. Login dengan kredensial di atas
3. Buka Elementor editor untuk test widget/shader
4. Untuk functional verify: buka halaman depan dan cek JS console

## Catatan

- Site ini adalah tunnel dari LocalWP — pastikan LocalWP sedang running sebelum akses
- Jika 502/error, restart site dari LocalWP app
- Jangan ubah settings admin yang无关 dengan testing
